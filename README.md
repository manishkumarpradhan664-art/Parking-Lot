📖 About The Project

Parking Lot Manager is a Java-based console application designed to manage vehicle parking efficiently. It helps users park vehicles, remove vehicles, search for vehicles, and manage waiting vehicles automatically.

This project demonstrates the practical implementation of various Data Structures such as Stack, Queue, Array, and HashMap.

The system also supports file handling to save and load parking information.

✨ Features

- 🚘 Park Vehicle: Allows users to park vehicles in available parking slots.
- 🚗 Remove Vehicle: Allows users to remove parked vehicles.
- 🔍 Search Vehicle: Searches for vehicles using vehicle numbers.
- 📊 Display Parking Status: Displays currently parked vehicles.
- ⏳ Waiting Queue: Maintains a waiting list when parking is full.
- 🔄 Automatic Slot Management: Automatically manages available parking spaces.
- 🚫 Duplicate Prevention: Prevents duplicate vehicle entries.
- 💾 File Handling: Saves and loads parking data using "parking.txt".
- ⚠️ Input Validation: Handles invalid inputs and exceptions.
